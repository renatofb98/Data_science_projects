
# Projeto Educacao INEP

Este diretório contém o projeto de análise e processamento dos microdados do Censo Escolar do INEP.

## Estrutura de Pastas

- `data/raw`: Dados brutos, inalterados, diretamente da fonte.
- `data/interim`: Dados intermediários, após limpeza e pré-processamento.
- `data/processed`: Dados finais, prontos para análise ou modelagem.
- `notebooks`: Jupyter notebooks para exploração, análise e desenvolvimento de modelos.
- `src`: Código-fonte de funções e scripts auxiliares.
